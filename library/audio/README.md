Drop royalty-free audio here to avoid paying for generated music/SFX:

- `music/<mood>.mp3` - e.g. `music/playful-adventure.mp3` (mood = the script's `music:` header)
- `sfx/<name>.wav`   - e.g. `sfx/rumble.wav`, `sfx/roar.wav` (name = the script's `SFX:` text)

Local files always win over ElevenLabs. Generated audio is cached in `generated/` (git-ignored).
